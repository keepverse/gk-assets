# Ice Shield source textures

This directory holds additional reusable Ice Shield source images. The
`T_IceShield_FrostPanels_Alternate.png` image is a generated frost-panel variant
preserved from the asset-generation session (source
`exec-03eb685f-7669-4d83-b3eb-9c8243c15ce0.png`). It is an available art
source, **not currently assigned** to a V3 shield material.

Other generated images from that session were already present byte-for-byte:

- `../v2/textures/T_IceShield_FrostVeins_RGBA_v2.png` matches
  `exec-98855cc5-6b8f-4ab8-9291-d0aa134c8fff.png`.
- `../v4/textures/T_IceShield_FrostPanels_v4_generated.png` matches
  `exec-81c839c3-413d-458d-be56-8bb53c0a597f.png`.

Keep the versioned textures beside their existing object-kit sources; moving
them would break those Blender files' relative paths. The v2 shell object kit
loads its frost-vein image from the tracked `v2/textures/` source file.

## Crystal mirror lookdev set

`mirror_v1/` contains deterministic, tileable PBR maps for the proposed
crystal-mirror idle. These are new sources for future meshes; the current idle
and its three linked Blender assets do not use them yet.

| Texture set | Intended object | Character |
|---|---|---|
| `T_IceShield_MirrorFace_*` | Broad mirror pane in each guard panel | Polished blue ice, wide facets, faint frost veins |
| `T_IceShield_PrismFrame_*` | Narrow beveled edge / support | Dark sapphire facets with restrained cyan edge light |
| `T_IceShield_GuardShard_*` | Small splinter attached to a mirror | Lighter faceted accent, kept sparse |

Each set contains `BaseColor` (sRGB), `Roughness` (linear grayscale),
`NormalGL` (tangent-space OpenGL normal; non-color data), `Emission` (linear,
white vein mask; non-color data), and `Height` (linear grayscale). Color and
layout are generated from fixed seeds by
`python tools/generate_ice_mirror_textures.py`; `--size` accepts power-of-two
maps from 256 through 4096. The contact sheet at
`assets/vfx/ice_shield/lookdev/ice_mirror_texture_preview.png` is ignored review
output and is regenerated by the same command.

## Mirror screen deploy

`mirror_screen_v1/T_IceShield_MirrorHexScreen_RGBA.png` is a dedicated
transparent blue frost-haze texture for `shield_ice_mirror_deploy`. Its soft,
low-frequency colour and opacity variation is generated deterministically by
`python tools/generate_ice_mirror_screen_texture.py`; it has no interior facet
seams or spokes. The single six-sided Blender mesh defines the screen outline,
with a separate equal-sided outer rim.
The ignored contact preview is
`assets/vfx/ice_shield/lookdev/ice_mirror_hexscreen_texture.png`.

## Snowflake particle sources

`snowflake_v1/` contains three centered 512×512 RGBA sprites with transparent
backgrounds. They are drawn by the deterministic in-repo generator
`python tools/generate_ice_snowflake_textures.py` and used by the
`shield_ice_mirror_idle` snowflake layer. The scene chooses a silhouette per
card, then varies scale, rotation, and path phase:

| Texture | Silhouette | Suggested use |
|---|---|---|
| `T_IceShield_Snowflake_Branching.png` | Fine six-arm dendrite | Larger flakes with visible branching |
| `T_IceShield_Snowflake_Lance.png` | Six long faceted spokes | Sharper, smaller flakes |
| `T_IceShield_Snowflake_Rosette.png` | Compact broad sixfold plate | Occasional dense crystal flakes |

The ignored contact sheet at
`assets/vfx/ice_shield/lookdev/snowflake_texture_preview.png` is regenerated by
the same script for source-art review.
